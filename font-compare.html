怎么看差别？重点盯这几处：
· 「把链接，变成」这行大字——看笔画的粗细对比与收笔（方案 C 的字母与汉字更"紧实"）
· 数字与英文——方案 C 的 Inter 更规整，方案 A 在 Windows 上会偏细
· 按钮文字——方案 C 的字重过渡更平滑
